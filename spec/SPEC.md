# Vault 文件契约

- 以消息发送时间在 Asia/Shanghai 时区的日期归档。每个活跃日期使用 `YYYY-MM-DD/YYYY-MM-DD.md`，同级创建 `assets/`。
- 资源引用为相对路径 `assets/{date}-{hash8}.{ext}`。hash 取内容 SHA-256 的前 8 位小写十六进制字符，同内容复用。8 位碰撞扩为 12 位，仍有碰撞时使用完整哈希。
- 同一日期按文件路径加锁。主文件通过同目录隐藏临时文件、fsync 和 rename 原子替换。启动时清理中断留下的主文件临时文件，历史命名不符合规范时记录告警。
- 通道消息 ID 是幂等主键。同一 ID 的重推在 7 天窗口内去重，过期记录可由服务清理。状态保存在 Vault 外的 SQLite。
- 客户端编辑器可依赖日期目录、文件名和相对路径。写入器用 HTML 注释标记自动生成的条目，编辑时应保留注释，方便中断恢复及冲突去重。
- 检测到冲突副本时，以主文件为准，合并能可靠识别的新增条目。无法识别的内容保留副本并告警。已合并副本归档至 `.conflicts/`，保留至少 30 天。
- 契约夹具覆盖通道数据、标准化类型和预期 Vault 文件。调整契约必须递增首行版本。
